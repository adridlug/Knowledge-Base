# GDB

### run program with gef
```
gdb $program
```
### set breakpoint at address
```
break *$address
```
### run (until breakpoints get hit)
```
r
```
### execute next instruction 
```
nexti
```
### show memory mapping of running program in gdb
```
info proc mappings
```
